# VAO Standard 0.6.0

These files come from the signed [VAO 0.6.0 release](https://github.com/modavis-project/vao-standard/releases/tag/v0.6.0),
commit `9d477213eab90defa75bef0f44e0d292a83e68d9`.
The source archive DOI is [10.5281/zenodo.23287792](https://doi.org/10.5281/zenodo.23287792).
The reference reader and its normative artifacts are unmodified. The 0.3 and 0.4
schemas are included because the reference reader uses them for core validation.
VAO Blender uses the reference reader for Core declarations, carrier mapping and byte
fixity. It reads MMIC package metadata without validating or executing MMIC domain data.
