# Vendored VAO 0.4.0 provenance

This directory contains the published VAO Standard 0.4.0 artifacts used by
VAO Blender 0.3.0. The source is the signed annotated Git tag `v0.4.0` at
<https://github.com/modavis-project/vao-standard> (commit `40fc376`) and its
GitHub release published on 2026-08-27.

- Release: <https://github.com/modavis-project/vao-standard/releases/tag/v0.4.0>
- DOI: <https://doi.org/10.5281/zenodo.22122774>
- Source archive: `vao-standard-0.4.0.zip`
- Source archive SHA-256:
  `2acbda0a257c7f71e2b57e01617678745de2ecf11197b4687aa623f71d23955d`

The archive is preserved byte-for-byte. Extracted documentation, schemas,
semantic artifacts, reference tools, fixtures, license, and notice are copied
from that release. `CONTRACT_FILES_SHA256` is VAO Blender's inventory of this
vendored directory; the normative artifact inventory remains
`Schemas/vao-release-bundle-0.4.0.json`.

The upstream `NOTICE` and `LICENSE` files govern the vendored material. In
summary, documentation, schemas, semantic artifacts, fixtures, and the OKF
bundle are CC BY 4.0; reference software, tests, and automation are Apache-2.0.
