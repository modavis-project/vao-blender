# Support

Use GitHub Discussions for usage questions and GitHub Issues for reproducible
bugs or feature requests. Before posting, check
[Installation](docs/INSTALLATION.md), [Compatibility](docs/COMPATIBILITY.md), and
[Troubleshooting](docs/TROUBLESHOOTING.md).

Include:

- VAO Blender version;
- Blender version and operating system/architecture;
- VAO format version and carrier mode;
- validation state and diagnostic code(s);
- concise reproduction steps and expected/actual behavior.

Remove absolute paths and personal information. Share package bytes only when you
have permission. Maintainers cannot grant rights to third-party VAO content,
certify scientific claims, or recover damaged source packages.

For vulnerabilities, use the private process in [SECURITY.md](SECURITY.md), not a
public issue. This is a community project; response times are best-effort.
